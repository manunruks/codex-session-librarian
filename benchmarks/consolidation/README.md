# Reproducible consolidation benchmark — 2026-11-05

This is a synthetic, local Linux comparison, not a universal compatibility ranking.
Use the source and result artifacts from the same reviewed commit. The corpus does
not import CSL's canonical representation: `fixtures.py` generates native JSONL
and implements a small independent observer of explicit text/tool/media fields.

## Structural comparison without accounts or commercial inference

Requirements: Linux with working bubblewrap user namespaces, Git, Python 3.11+,
Node 22 and npm. Dependency download needs network; conversions run without it.
Private home directories and the user runtime bus are masked, environment variables
are allowlisted, and only synthetic lab files are writable.

From a checkout containing this benchmark:

```sh
CSL_BENCH_WORKSPACE=$(mktemp -d)
python3 benchmarks/consolidation/prepare.py \
  --workspace "$CSL_BENCH_WORKSPACE" --csl-repo "$PWD"
python3 "$CSL_BENCH_WORKSPACE/benchmark/install.py" session-porter --workspace "$CSL_BENCH_WORKSPACE"
python3 "$CSL_BENCH_WORKSPACE/benchmark/install.py" sessionport --workspace "$CSL_BENCH_WORKSPACE"
python3 "$CSL_BENCH_WORKSPACE/benchmark/install.py" claude-session-teleporter --workspace "$CSL_BENCH_WORKSPACE"
python3 "$CSL_BENCH_WORKSPACE/benchmark/run.py" \
  --workspace "$CSL_BENCH_WORKSPACE" --gate-reviewed \
  --media-venv "$HOME/.local/share/csl/media-venv"
python3 "$CSL_BENCH_WORKSPACE/benchmark/adjudicate.py" \
  --results "$CSL_BENCH_WORKSPACE/benchmark/results"
```

The optional media interpreter is the existing decoder from `install-media.sh`;
record its actual dependency versions. Without it, the image case is not a valid
test of CSL's configured media capability. `--gate-reviewed` is an explicit
operator checkpoint, not an automatic assertion that an audit happened.

Nine cases, both source CLIs, four tools: short text, contradictory decisions,
tool-only fact, completed/error tools, branches/partial ancestry, valid embedded
PNG, unsupported content, truncated JSONL and an altered package. The package
receive operation is not shared by all projects and is marked not applicable.

## Three different evidence layers

1. `results.json`: generated native records and explicit semantic checks.
   `adjudicated-results.json` additionally explains rejections, non-shared operations
   and unsupported media. Its reviewed status covers the first leg; inspect the
   separate `roundtrip` result before describing return-trip fidelity.
2. `native-results.json`: exact generated bytes loaded in real CLIs without network.
   Codex `thread/read` measures file acceptance and visible-history representation;
   Claude captures reconstructed requests on localhost, stopping before generation.
   These are deliberately different measurements, identified by method.
3. `live-results.json`: separately authorized paid continuations, one trial per
   case/model. A parser or successful file load does not prove this layer.

Native checks must use `native_isolated.py`, with the installed Linux ELF binaries
(Codex's npm JS wrapper is not the ELF):

```sh
python3 "$CSL_BENCH_WORKSPACE/benchmark/native_isolated.py" \
  --workspace "$CSL_BENCH_WORKSPACE" \
  --codex-bin /path/to/installed/native/codex \
  --claude-bin /path/to/installed/native/claude
```

The wrapper denies external network access. No real credentials are supplied.
Codex never starts a turn in this layer. Claude receives only a dummy key and a
rejecting local endpoint; historical tools cannot execute a model-generated turn.

## Paid reproduction, only when explicitly authorized

`live.py` uses the existing CSL live runner, disables tools and accepts only the
known synthetic corpus cases. Supply a dedicated authenticated Codex test home;
never use or copy a normal user's authentication/history. Supply Anthropic key
and any required workspace header in memory through your own private helper.
The benchmark does not acquire credentials, grant access or create accounts.

```sh
python3 "$CSL_BENCH_WORKSPACE/benchmark/live.py" \
  --workspace "$CSL_BENCH_WORKSPACE" --csl-repo "$PWD" \
  --allow-paid --targets both --codex-home /path/to/dedicated/test-home \
  --max-calls 16 --claude-budget-usd 0.10 --out /path/to/new/private/results
```

One attempt per case; failures are retained. Thresholds are not billing guarantees.
Codex plan tokens and Anthropic CLI dollar estimates are reported separately.
Public results contain synthetic answers/usage only, never authentication files,
credential values, provider headers or private runtime helpers.

## What the results establish

The checked text/tool cases passed both structural directions and return trips for
CSL and Teleporter. Session Porter's first Claude→Codex leg retained the tested
tool data, but some reverse/return cases lost assistant text or error state.
Sessionport's Claude→Codex custom tool records are recognized and retained by the
observer; its generated Codex IDs were rejected by the installed CLI. Do not
misreport custom tools as missing function calls.

All three of CSL, Session Porter and Teleporter answered 4/4 paid recall cases;
sessionport answered 1/4. This small sample is not a population success rate.
Teleporter retained tool markers in Codex's visible `thread/read` representation
that CSL did not show; both recovered those facts by model. That is a concrete
presentation advantage for Teleporter, not evidence that CSL lost model history.

CSL preserved the tested PNG bytes and return trips; Teleporter explicitly uses
media placeholders. Other exercised routes did not retain the image. Those are
coverage differences, not a claim that every project promises supported media.

The observer does not establish every timestamp, reference, parent relationship,
phase, opaque state or asset type. Branch selection, incomplete ancestry and
unsupported blocks require their recorded policy interpretation. Unknown fields
must not be silently converted into a pass. No aggregate score is computed.

## Evidence files

The `results/` directory contains reviewed/raw rows, native checks, sanitized live
results, timings and environment metadata. `artifacts.json.gz` contains only
synthetic source/target/return transcripts and captured command logs, indexed by
case. Inspect with Python's `gzip` and `json`; never execute historical tool text.
`evidence-sha256.json` identifies the exact accompanying artifacts.

Earlier harness mistakes (PNG CRC, metadata/flags, custom tool observation and a
Codex provider-routing smoke test) were corrected before conclusions. The latter
made unauthenticated synthetic requests and is not counted as paid recall evidence;
the final native layer is enforced without external network access. Full chronology
is in the consolidation report; no failed measurement is reclassified as a pass.
